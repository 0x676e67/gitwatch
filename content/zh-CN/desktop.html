添加第一个任务

gitwatch desktop
  1. 点击添加任务，从任务类型下拉框中选择工作空间备份、Git 监听或定时拉取。
  2. 填写任务名称，选择源目录，再设置该模式的选项。
  3. 保存任务。新任务会出现在列表中，保持停止状态。
  4. 选中任务，点击执行一次试运行，或点击启动让它持续运行。

管理运行中的任务

编辑或移除任务之前，请先停止任务。

添加任务或打开设置时，任务列表会一直显示。点击任意任务即可回到详情。拖动任务卡片上的六点手柄可调整顺序，结果会保存。拖到列表边缘可以滚动，按 Escape 可以取消拖动。

操作作用
启动 / 停止启用或停止任务。已启动的任务会在下次打开桌面应用或 TUI 时恢复运行。
执行一次停止的任务执行一遍；运行中的任务请求立即执行。不改变任务的启动状态。
刷新重新加载任务，并请求更新仓库信息。
活动记录查看操作结果和错误。更新失败时，可以先查看这里。

如果操作正在执行，新请求会等它结束。多次等待中的请求会合并为一次。手动拉取完成后，会重新开始下一次拉取的倒计时。

分开管理任务列表

多工作空间功能将包含在下一次发布中；v0.2.0 只有一个任务列表。

首次打开应用时，默认工作空间已经可以使用。v0.2.0 的任务和备份历史会留在这里，启动状态和拉取计划也会保留。

  1. 点击新建工作空间。
  2. 填写名称和专用备份仓库的远程地址。每个自定义工作空间都必须配置远程仓库。仓库地址明文显示，方便核对和编辑；访问权限由 Git 认证控制。
  3. 保存后，从工作空间菜单中选择它，再添加任务。

每个工作空间都有自己的任务列表和备份历史。工作空间备份仍是一种任务类型；任意工作空间都可以添加备份、监听和拉取任务。工作空间的备份远程与监听、拉取任务使用的远程各自独立。

切换只改变当前显示的列表，其他工作空间中已启动的任务会继续运行。重新打开应用后，所有工作空间的已启动任务都会恢复，上次选择的工作空间和已保存的拉取截止时间也会保留。

默认工作空间在本地使用，不能在界面中更改它的备份远程；旧版本已经配置的远程会继续保留。自定义工作空间可以在备份设置中更改远程、选择自动上传，或获取并导入备份分支。

重命名工作空间只改变显示名称，不搬移数据。当前工作空间没有任务时，才可以移除工作空间；它的备份数据仍留在磁盘上。默认工作空间不能重命名或移除。

调整界面布局

拖动任务列表右侧的分隔线可以调整列表宽度。向上拖动活动记录的顶部边缘可以扩大日志区域，点击标题可以折叠。

日志会自动换行，也可以选中文字复制。复制日志会复制当前工作空间显示的日志；清空日志只清空这个视图，不会删除任务或备份历史。阅读较早的内容时，可以关闭跟随最新日志。视图最多保留 200 条记录。

默认工作空间在本地使用，因此不显示备份远端设置。选中自定义工作空间后可以配置远端。添加任务时，从任务类型下拉框选择模式；如果保存失败，输入会保留在表单中，可以修改后重试。

浏览与恢复备份

选中工作空间备份任务后打开历史记录，选择版本并预览文件，核对内容后再确认恢复。单纯预览不会写入源目录。关于恢复副本和预览有效期，请参阅恢复流程。

查看仓库信息

详情面板显示仓库链接、分支、最近提交、提交数量、贡献者数量、标签和已提交文件数。点击仓库链接可以在浏览器中打开远程页面。

统计使用本地 Git 的 HEAD，包含合并提交。浅克隆的历史可能不完整。文本行数包含注释和空行，文件类型按扩展名分类，并非语法分析得到的语言统计。二进制文件单独计数。

打开详情时会在后台更新信息，也可以点击刷新信息立即请求。统计过程不进行网络请求。提交时间按本地时间显示。

在托盘中继续运行

关闭或最小化窗口后，任务仍在托盘后台运行。点击托盘图标可重新打开窗口。要停止任务并退出应用，请右键托盘图标，选择退出。

在设置中启用启动时最小化到托盘，下次启动时会隐藏窗口。此选项默认关闭，无论是否启用，已启动任务都会恢复。应用不会安装系统服务，执行任务时需要保持 gitwatch 运行。
