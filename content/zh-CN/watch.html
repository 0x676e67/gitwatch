监听文件或目录

gitwatch ./notes
gitwatch -s 2 -r origin -b main ./notes
gitwatch -f -m "Notes: %d" ./notes
gitwatch watch ./notes --once

目标需要位于 Git 仓库中。第二条命令在变化稳定两秒后提交，并推送到 origin 的 main 分支。第三条命令会在启动时提交已有改动，并使用自定义提交消息；%d 会替换为日期和时间。最后一条只执行一次然后退出。

哪些内容会被提交

只提交指定文件或目录内的变化，遵循 Git 忽略规则，并记录删除。如果该路径内已有暂存的改动，gitwatch 会等待你处理；路径之外的暂存内容保持原样。

没有 -f 时，已有改动会作为初始状态，后续发生变化才触发提交。gitwatch 结合文件系统事件与周期性的内容检查。如果文件通知不可靠，可以使用 --polling。

其他 Git 操作尚未完成时，gitwatch 会等待。需要你完成或中止该操作后，才能继续自动提交。

从 shell 版本迁移

选项行为
-R推送前执行拉取并变基，默认关闭。
-x筛选触发提交的事件，不用于排除提交中的文件。
-c运行命令生成提交消息。除非显式调用 shell，否则不经过 shell 执行。
-h / -C这两个选项不接收参数。

完整选项见 gitwatch watch --help。命令失败会返回非零退出码。本项目是独立实现，替换原有 shell 脚本安装时，请核对你依赖的选项。
