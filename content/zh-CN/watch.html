创建监听任务

  1. 点击添加任务，选择 Git 监听。
  2. 选择已有 Git 仓库中的目录或文件。
  3. 设置用于合并连续变更的等待时间，保存任务。
  4. 点击一次提交更改，或启动自动运行。

gitwatch 会等文件变动暂时平稳后再提交，并遵循 Git 忽略规则。此模式会在源仓库中暂存和提交文件；需要独立历史时，请选择文件备份。

可选的上传

如需推送新提交，填写远端名称，例如 origin，并按需指定分支。远端留空则不上传。请先在 Git 中配置远端和认证。推送不会强制覆盖远端历史。

与 Git 操作配合

切换分支、变基或手动处理冲突前，请先暂停任务。提交或推送失败时，在活动记录中查看原因。监听任务不代替通用的合并工具。
