语言与时间

首次启动跟随系统语言，不支持的语言回退到英语。语言选择器会保存偏好，环境变量 GITWATCH_LANG 可用 en 或 zh-CN 覆盖该选择。Git 自身的消息和文件内容不会翻译。

最近提交只显示一个时间，使用系统时区，格式为 YYYY-MM-DD HH:MM:SS。这是提交时间，不是服务器收到推送的时间。

数据与缓存目录

系统应用数据
Windows%LOCALAPPDATA%\gitwatch\data
macOS~/Library/Application Support/gitwatch
Linux$XDG_DATA_HOME/gitwatch，默认 ~/.local/share/gitwatch

启动前设置 GITWATCH_DATA_DIR 可指定其他数据目录，请放在备份源项目之外。同一数据目录只能由一个应用实例使用。

更新检查缓存单独存放：Windows 使用 %LOCALAPPDATA%\gitwatch\cache，macOS 使用 ~/Library/Caches/gitwatch，Linux 使用 $XDG_CACHE_HOME/gitwatch，通常为 ~/.cache/gitwatch。

迁移应用数据

先从托盘退出，再复制整个数据目录。配置、备份仓库、恢复文件、spaces/ 和 spaces.json 要一起保留。切换工作空间不会停止任务。另一台电脑的源路径不同时，通常使用远程恢复向导更方便。

更新或卸载

打开应用设置 → 管理安装。官方归档安装可以点击检查更新，阅读版本说明后确认。程序会先停止所有任务，再替换安装。按提示关闭程序，然后重新打开已安装的文件。

卸载应用同样需要确认，只移除程序，保留任务设置、备份历史和恢复数据。

Cargo 或其他包管理器安装需要通过原包管理器处理。操作前先退出 gitwatch。更新 Cargo 安装：

cargo install gitwatch --locked --force

卸载使用 cargo uninstall gitwatch。本地源码安装先更新源码，再执行 cargo install --path . --locked --force。使用自定义 Cargo 安装根目录时，保持原设置。

安装中断

更新中断后，重新打开 gitwatch，按提示恢复原安装；恢复完成后再打开一次程序。确认能够正常启动前，请保留安装目录中的恢复文件。

版本提示

后台会检查新的稳定版本，结果缓存一天，不会自动安装。设置 GITWATCH_NO_UPDATE_CHECK=1 可关闭自动检查；支持应用内更新的安装仍可手动检查。
