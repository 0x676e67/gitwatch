你想做什么？

目标选择
备份指定文件，不向项目仓库添加提交文件备份
在两台电脑上持续更新这些文件为备份任务启用双向同步
直接在项目仓库中提交文件变化Git 监听
定时把远端提交拉取到普通 Git 仓库定时拉取

从一个任务开始

  1. 安装 Git 和 gitwatch，然后打开 gitwatch。
  2. 点击添加任务，选择任务类型和本地目录。
  3. 保存后先用任务的一次性操作检查结果，准备好后点击启动自动运行。

如果要在另一台电脑上使用已有备份，请先恢复远程备份。仅创建任务不会下载备份文件。

桌面应用

gitwatch 支持 Windows、macOS 和 Linux，内置英语和简体中文。已启动的任务可以在托盘中继续运行。
