安装 gitwatch →了解桌面应用

选择适合你的任务模式

gitwatch 是受 gitwatch/gitwatch 启发的 Rust 实现，支持 Windows、macOS 和 Linux。命令行、终端界面和桌面应用共用同一个业务核心。

01 / watch随时记录文件变化监听文件或目录，在源项目的 Git 仓库中提交变化。→02 / workspace备份指定文件把笔记或项目文件保存到独立 Git 仓库，每个工作空间使用一个分支。→03 / pull定期更新本地仓库按设定的间隔拉取远程更新，并选择拉取策略。→

开始监听

安装 Git 和 gitwatch 后，指定现有 Git 仓库中的一个目录：

gitwatch ./notes

修改目录中的文件，等待变化稳定后，gitwatch 就会创建提交。按 Ctrl+C 停止。启动时已有的改动会作为初始状态；如果也要立即提交这些改动，可以加上 -f。

监听模式会在源项目中写入 Git 提交。如果想让源项目的提交历史保持原样，请使用工作空间备份。

选择使用界面

gitwatch --help
gitwatch tui
gitwatch desktop

使用交互界面前，需要安装包含对应构建功能的版本。它们共用本地数据，并记住已启动的任务。同一数据目录同时只能由一个交互界面使用。
