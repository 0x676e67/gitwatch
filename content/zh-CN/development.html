本地构建

安装 Rust 1.96 或更新版本、Git，以及适用的 Linux 依赖。crate 只构建一个桌面程序，没有界面 feature 开关。

cargo build --locked
cargo run --locked

运行检查

cargo +nightly fmt --all --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo doc --locked --no-deps
cargo package --locked

测试使用临时仓库。手动实验请通过 GITWATCH_DATA_DIR 指定独立数据目录，不要对真实文件进行破坏性的同步测试。

发布构建

CI 覆盖 Windows、macOS 和 Linux。版本标签会触发发布构建、校验和生成以及 crates.io 授信发布。归档包含桌面程序、安装清单和许可证。源码及发布版本可在 GitHub 查看。

文档

双语文档站位于独立的 gh-pages 分支，使用 Python 3.11 或更新版本，不依赖第三方包。提交前运行 python build.py 和 python check.py，检查链接和双语章节对应关系。

Rust 代码采用 Apache-2.0 许可证；内置字体的 OFL-1.1 许可证和声明位于 src/fonts/。
