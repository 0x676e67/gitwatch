准备环境

安装 Git，确认终端中可以运行 git --version。创建提交前，需要设置 Git 作者身份：

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

上面的设置对所有仓库生效。如果只想设置某个仓库，请进入该仓库后去掉 --global 再运行。

安装已发布版本

从 GitHub Releases 下载对应平台的压缩包，核对 SHA-256 校验值后解压。Git 需要单独安装。目前提供 Windows x86-64、Linux x86-64 和 macOS Apple Silicon 的压缩包。

也可以使用 Rust 1.96 或更新版本，从 crates.io 安装：

cargo install gitwatch --locked                     # 仅 CLI
cargo install gitwatch --locked --features tui      # CLI + TUI
cargo install gitwatch --locked --all-features      # CLI + TUI + 桌面应用
最新已发布版本是 v0.1.0。本文档展示当前源码版本，包含语言切换、托盘和较新的任务控制功能。使用这些功能需要从源码安装。

从源码安装

git clone https://github.com/0x676e67/gitwatch.git
cd gitwatch
cargo install --path . --locked --all-features
gitwatch desktop

只需要 CLI 和 TUI 时，把 --all-features 换成 --features tui；只需要 CLI 时，省略功能选项即可。桌面程序名为 gitwatch-desktop，也可以通过 gitwatch desktop 启动。

Linux 桌面依赖

构建桌面应用需要 X11/Wayland、OpenGL 和 xkbcommon 的开发包。Ubuntu 可以使用：

sudo apt-get install libxkbcommon-dev libwayland-dev libx11-dev libxi-dev libgl1-mesa-dev

CLI 不需要这些桌面库。GUI 仍然使用系统的窗口和图形库，并不是完全独立于系统组件的图形环境。

托盘通过 D-Bus StatusNotifierItem 工作，不依赖 GTK 或 AppIndicator 库。桌面环境需要兼容的托盘宿主；GNOME 可能需要安装托盘扩展。如果无法创建托盘图标，应用会显示窗口，关闭窗口即退出。
