安装 Git

gitwatch 会调用电脑上的 Git 程序。先安装 Git，再打开新终端，确认 git --version 可以运行。Windows 可以使用：

winget install --id Git.Git -e --source winget

Git 监听会直接在项目中创建提交。如果还没有配置作者身份，请在该仓库目录中执行：

git config user.name "Your Name"
git config user.email "you@example.com"

远程操作使用已有的 Git 凭据或 SSH 配置，请确保对应账号拥有仓库访问权限。

下载发布版本

从 GitHub Releases 下载对应平台的归档，对照 SHA256SUMS 验证 SHA-256。把整个归档解压到可写目录；保留程序旁的 gitwatch-install.json，应用内更新需要它。

预编译包支持 Windows x86-64、Linux x86-64 和 macOS Apple Silicon。在 Windows 打开 gitwatch.exe；在 macOS 或 Linux 的解压目录运行 ./gitwatch。Git 需要另外安装。

使用 Cargo 安装

需要 Rust 1.96 或更新版本：

cargo install gitwatch --locked
gitwatch

默认安装即为桌面应用，不需要 feature 选项或子命令。

从源码构建

git clone https://github.com/0x676e67/gitwatch.git
cd gitwatch
cargo install --path . --locked
gitwatch

Linux 桌面依赖

在 Ubuntu 上，编译前安装这些开发依赖：

sudo apt-get install libxkbcommon-dev libwayland-dev libx11-dev libxi-dev libgl1-mesa-dev

应用使用系统的显示服务和图形库，需要图形会话。托盘通过 D-Bus StatusNotifierItem 工作，需要兼容的托盘宿主；GNOME 可能需要托盘扩展。如果无法创建托盘图标，窗口会保持可见，关闭窗口即可退出。

正在使用旧版本？更新前请阅读 0.4 升级说明。
