Create a watch task

  1. Choose Add task and select Git watch.
  2. Choose a directory or file inside an existing Git repository.
  3. Set the delay used to group changes, then save.
  4. Use Commit changes once, or start automatic runs.

gitwatch waits for changes to settle before committing. Git ignore rules apply. This mode stages and commits in the source repository; choose file backup for separate history.

Optional upload

Set a remote name, such as origin, and an optional branch to push new commits. An empty remote disables upload. Configure authentication and the remote in Git first. Pushes do not force-overwrite remote history.

Working alongside Git

Pause the task before branch changes, rebases or manual conflict resolution. Review the activity log if a commit or push fails. A watch task does not act as a general merge tool.
