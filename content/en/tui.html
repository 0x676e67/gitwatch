Open the terminal interface

Install with --features tui or --all-features, then run:

gitwatch tui

The TUI uses the same task settings and backup store as the desktop and CLI. Quit the other interactive interface before opening it with the same data directory.

Common shortcuts

KeyAction
nAdd a task
F2Select the task mode in the form
Tab / Ctrl+SMove between fields / save
s / bStart or stop / run once
hOpen backup history
v / RPreview a restore / open confirmation
F3Switch language and save the choice
q / Ctrl+CExit

Shortcuts depend on the current view; the footer lists the actions available there. In a pull form, use Left/Right or Space on the strategy field.

Stopping and resuming

Quitting waits for current operations to finish and stops the workers. Started tasks are remembered and resume when you reopen the TUI or desktop. Use the task's Stop action if you want it to remain stopped.

For Chinese text, choose a terminal font that includes Chinese characters. Unlike the desktop app, the TUI uses your terminal's font.
