Open the terminal interface

Install with --features tui or --all-features, then run:

gitwatch tui

The TUI uses the same task settings and backup store as the desktop and CLI. Quit the other interactive interface before opening it with the same data directory.

Common shortcuts

KeyAction
nAdd a task
F2Select the task mode in the form
Tab / Ctrl+SMove between fields / save
s / bStart or stop / run once
hOpen backup history
v / RPreview a restore / open confirmation
F3Switch language and save the choice
q / Ctrl+CExit

Shortcuts depend on the current view; the footer lists the actions available there. In a pull form, use Left/Right or Space on the strategy field.

Switch and manage workspaces

These controls are part of the next release and are not available in v0.2.0.

Press F4 to open the workspace list. Use the arrow keys to highlight a workspace and Enter to switch to it. The asterisk marks the current workspace. Tasks you started in other workspaces keep running.

Key in the workspace viewAction
nCreate a workspace with a name and required backup remote
Tab / Ctrl+SMove between fields / save
eRename the current workspace
xRemove the current workspace if it has no tasks; keep its data
EscCancel the form or close the workspace view

After creating a workspace, select it from the list to add tasks there. Rename and remove apply to the current workspace, not the highlighted row. The default workspace always remains available and contains your existing tasks.

In a custom workspace's task view, press u to edit its backup remote. The remote cannot be empty. Ctrl+P toggles automatic upload in that form; Enter saves it. The default workspace's backup remote cannot be changed in the interface. See workspace behavior for details.

Stopping and resuming

Quitting waits for current operations to finish and stops the workers. Started tasks are remembered and resume when you reopen the TUI or desktop. Use the task's Stop action if you want it to remain stopped.

For Chinese text, choose a terminal font that includes Chinese characters. Unlike the desktop app, the TUI uses your terminal's font.
