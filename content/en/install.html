Requirements

Install Git and make sure git --version works in your terminal. Configure your Git author identity before creating commits:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

These commands set the identity for all your repositories. To set it for just one repository, run them there without --global.

Published release

Download an archive for your platform from GitHub Releases, verify its SHA-256 checksum, and extract it. Git must be installed separately. Archives are available for Windows x86-64, Linux x86-64 and macOS Apple Silicon.

Or install from crates.io with Rust 1.96 or newer:

cargo install gitwatch --locked                     # CLI
cargo install gitwatch --locked --features tui      # CLI + TUI
cargo install gitwatch --locked --all-features      # CLI + TUI + desktop
The latest published release is v0.1.0. This guide shows the current source build, including language selection, tray support and newer task controls. Build from source to use those features.

Build from source

git clone https://github.com/0x676e67/gitwatch.git
cd gitwatch
cargo install --path . --locked --all-features
gitwatch desktop

Use --features tui instead of --all-features for CLI and TUI, or omit the feature option for the CLI alone. The desktop executable is named gitwatch-desktop; gitwatch desktop launches it.

Linux desktop dependencies

Building the desktop app needs development packages for X11/Wayland, OpenGL and xkbcommon. On Ubuntu:

sudo apt-get install libxkbcommon-dev libwayland-dev libx11-dev libxi-dev libgl1-mesa-dev

The CLI does not need desktop libraries. The GUI still uses the operating system's windowing and graphics libraries; it is not a fully self-contained graphical environment.

The tray uses D-Bus StatusNotifierItem without GTK or AppIndicator libraries. A compatible tray host is required; GNOME may need a tray extension. If gitwatch cannot create a tray icon, the window stays visible and closing it exits.
