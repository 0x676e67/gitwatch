Install Git

gitwatch uses the Git executable on your computer. Install Git and check that git --version works in a new terminal. On Windows:

winget install --id Git.Git -e --source winget

Direct watching creates commits in your project. If necessary, configure the author identity inside that repository:

git config user.name "Your Name"
git config user.email "you@example.com"

Remote operations use your existing Git credentials or SSH setup. Make sure that account can access the repository.

Download a release

Download your platform's archive from GitHub Releases and compare its SHA-256 checksum with SHA256SUMS. Extract the entire archive into a writable folder. Keep gitwatch-install.json beside the program; the in-app updater needs it.

Archives cover Windows x86-64, Linux x86-64 and macOS Apple Silicon. Open gitwatch.exe on Windows, or run ./gitwatch from the extracted folder on macOS or Linux. Git is installed separately.

Install with Cargo

With Rust 1.96 or newer:

cargo install gitwatch --locked
gitwatch

The default installation includes the desktop app. No feature flags or subcommands are needed.

Build from source

git clone https://github.com/0x676e67/gitwatch.git
cd gitwatch
cargo install --path . --locked
gitwatch

Linux desktop dependencies

On Ubuntu, install these build dependencies before compiling:

sudo apt-get install libxkbcommon-dev libwayland-dev libx11-dev libxi-dev libgl1-mesa-dev

The app uses the system display server and graphics libraries, and needs a graphical session. Its tray uses D-Bus StatusNotifierItem with a compatible tray host; GNOME may need a tray extension. If a tray icon cannot be created, the window stays visible and closing it exits.

Coming from an older release? Read the 0.4 migration guide before updating.
