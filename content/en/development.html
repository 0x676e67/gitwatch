Build locally

Install Rust 1.96 or newer, Git and the Linux libraries if applicable. The crate builds one desktop executable with no interface feature switches.

cargo build --locked
cargo run --locked

Run checks

cargo +nightly fmt --all --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo doc --locked --no-deps
cargo package --locked

Tests use temporary repositories. Keep manual experiments in a separate data directory using GITWATCH_DATA_DIR; do not test destructive sync scenarios against real files.

Release builds

CI checks Windows, macOS and Linux. Version tags trigger release builds, checksums and crates.io Trusted Publishing. Archives include the executable, installation receipt and licenses. Releases and source are on GitHub.

Documentation

The bilingual site lives on the separate gh-pages branch. It uses Python 3.11 or newer without third-party packages. Run python build.py and python check.py to validate links and translation sections before submitting changes.
