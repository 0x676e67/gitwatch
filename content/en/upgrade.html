Reinstall once

The 0.3.x updater expects a two-program archive and cannot install the new single-program package. Use Cargo or a fresh release download for this upgrade.
  1. Quit every gitwatch instance from its tray menu.
  2. For Cargo, run cargo install gitwatch --version 0.4.0 --locked --force. For archives, download 0.4.0 and extract the whole archive into a new folder.
  3. Open the new gitwatch without arguments. Update shortcuts to point to it.

Application data paths are unchanged. Tasks and backups stay in their data directory. Copy the whole data directory before upgrading if you want a rollback copy. Do not copy the old installation receipt into the new folder.

What changed?

  • gitwatch opens the desktop directly. Old desktop and tui subcommands and task-management commands are removed.
  • There is no separate gitwatch-desktop program and no interface feature flags.
  • Use App settings → Manage installation for supported archive installations, or your package manager for managed installations.
  • Use the language selector or GITWATCH_LANG, and GITWATCH_DATA_DIR for another store. The old command-line flags are gone.

gitwatch --version still checks the version without opening a window.

Existing backup tasks

Existing backups do not become two-way sync tasks automatically. Follow the sync setup and confirm the first preview on each computer to receive remote file changes.
