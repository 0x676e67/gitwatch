Language and time

First launch follows the system language, falling back to English for unsupported languages. The language selector saves your preference. GITWATCH_LANG overrides it with en or zh-CN. Git's own messages and file contents stay unchanged.

The latest commit shows one timestamp in your system timezone as YYYY-MM-DD HH:MM:SS. This is a commit timestamp, not the time a server received a push.

Data and cache directories

SystemApplication data
Windows%LOCALAPPDATA%\gitwatch\data
macOS~/Library/Application Support/gitwatch
Linux$XDG_DATA_HOME/gitwatch, or ~/.local/share/gitwatch

Set GITWATCH_DATA_DIR before starting to use another data directory. Keep it outside projects being backed up. Only one app instance can use a data directory.

Update-check cache is separate: %LOCALAPPDATA%\gitwatch\cache on Windows, ~/Library/Caches/gitwatch on macOS, and $XDG_CACHE_HOME/gitwatch (normally ~/.cache/gitwatch) on Linux.

Move application data

Choose Quit from the tray, then copy the entire data directory. Keep configuration, backup repositories, recovery files, spaces/ and spaces.json together. Switching workspaces does not stop tasks. On a computer with different source paths, the remote restore wizard is usually easier than copying the store.

Update or uninstall

Open App settings → Manage installation. For an official archive installation, choose Check for updates, read the release notes, and confirm. The app stops all task workers before replacing the program. Close it when prompted, then reopen the installed executable.

Uninstall application also asks for confirmation. It removes the program while keeping task settings, backup history and recovery data.

Cargo and other package-manager installations use that manager. Quit gitwatch first. To update a Cargo installation:

cargo install gitwatch --locked --force

To uninstall it, use cargo uninstall gitwatch. For local source installs, update the source and repeat cargo install --path . --locked --force. Preserve any custom Cargo installation root.

Interrupted installations

After an interrupted update, reopen gitwatch and accept the prompt to restore the previous installation. Reopen once more after recovery. Keep installation recovery files until the app starts successfully.

Version notices

Background checks look for newer stable releases and cache results for a day. They do not install automatically. Set GITWATCH_NO_UPDATE_CHECK=1 to disable automatic checks; explicit checks remain available for supported installations.
