Workspaces

A default workspace is created automatically. It keeps existing tasks and stores backups locally, with no backup remote. For remote backups, create a workspace and supply its dedicated Git repository URL.

The workspace selector changes the task list you see. Tasks already running elsewhere continue in the background. Each workspace has its own tasks, order and backup history. Language and tray preferences apply to the whole app.

Create and run tasks

  1. Choose Add task and select file backup, Git watch or scheduled pull.
  2. Enter a name, select the local directory, complete that task's options, and save.
  3. Select the task from the list to see its state, actions and repository information.

One-time actions are named for what they do: back up files, commit changes, pull now or sync now. They work whether automatic runs are started or paused. Started tasks and scheduled deadlines are remembered across app restarts.

Pause automatic runs before editing a task. Names must be unique within a workspace, including names that differ only by case. Drag a task card's handle to reorder it.

Restore existing files

Choose Restore remote backup to bring a backup from another computer. The wizard loads backup branches, asks for the destination, then shows a file preview. Files are written only after Confirm restore. See the restore walkthrough.

Progress and activity

Task cards show their state. Scheduled pulls and sync tasks show the next check countdown. The activity panel records task names, results and errors, with copy and clear controls. Repository links open in your browser.

A local backup does not necessarily mean it has been uploaded; check the upload result too. Regular backups do not automatically download remote files. Enable two-way sync for that behavior.

Tray and exit

When the tray is available, closing the window hides it while tasks continue. Use the tray menu to show the window or choose Quit to stop tasks and exit. App settings can also start the window hidden in the tray.
