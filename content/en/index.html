gitwatch is a Rust implementation inspired by gitwatch/gitwatch. It runs on Windows, macOS and Linux. The CLI, terminal UI and desktop app share the same core.

Your first watch

With Git and gitwatch installed, point it at a directory inside an existing Git repository:

gitwatch ./notes

Edit a file in that directory. After the changes settle, gitwatch creates a commit. Press Ctrl+C to stop. Existing changes are the starting baseline; add -f if you want to commit those at startup too.

Watch mode writes commits into your source repository. Choose workspace backups if you want to keep the source project's Git history untouched.

Use the interface that suits you

gitwatch --help
gitwatch tui
gitwatch desktop

The interactive interfaces need their corresponding build features. They save tasks in the same local store and remember which tasks you started. Only one interactive interface can use a store at a time.
