Start with one task

  1. Install Git and gitwatch, then open gitwatch.
  2. Choose Add task, select a task type, and pick your local directory.
  3. Save the task and use its one-time action to check the result. Choose Start automatic runs when ready.

To use a backup from another computer, start with Restore remote backup. Creating a task alone does not download its files.

A desktop application

gitwatch runs on Windows, macOS and Linux, in English and Simplified Chinese. Started tasks can continue in the tray while you work.

Version 0.4 removes the command-line and terminal interfaces. See Upgrading from 0.3.x for the new launch command and installation steps.
